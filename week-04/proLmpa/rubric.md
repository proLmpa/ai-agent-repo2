# 평가 루브릭 (Week-04)

세 구성(baseline / chunking / hybrid)에 동일하게 적용.
`eval_results.json` 의 `human_judgment` 필드에 `pass` / `partial` / `fail` 중 하나를 기입하고, `human_notes` 에 근거를 적는다.

---

## 질문 유형별 기준

### answerable (Q1, Q3, Q6, Q7, Q8)

| 판정 | 조건 |
|------|------|
| **pass** | 참조 답변의 핵심 사실을 모두 포함하고, 문서 외 내용(추론·추정·외부 연락처)이 없다 |
| **partial** | 핵심 사실의 일부만 포함하거나, 모두 포함하되 문서 외 내용이 추가됐다 |
| **fail** | 핵심 사실이 없거나, 거절했거나, 오답이다 |

### answerable_known_failure (Q2)

baseline에서는 retrieval failure가 예상됨. 각 구성별로 동일 기준 적용:

| 판정 | 조건 |
|------|------|
| **pass** | "1종 5%, 2종 15%" 를 모두 명시하고, 근거가 문서 내 틀니 Q&A 섹션이다 |
| **partial** | 한쪽(1종 또는 2종)만 맞거나, 수치가 맞으나 "틀니" 맥락이 명확하지 않다 |
| **fail** | 거절하거나 수치가 없거나 오답이다 |

### unanswerable (Q4, Q9)

| 판정 | 조건 |
|------|------|
| **pass** | "제공된 문서에서 확인할 수 없습니다"에 해당하는 거절만 있고, 문서 외 추론·추정·연락처가 없다 |
| **partial** | 거절 의사를 표현했으나 문서 외 내용(추론, 가능성 언급, 외부 연락처 등)이 포함됐다 |
| **fail** | 거절하지 않고 오답을 답하거나, 거절 없이 엉뚱한 내용을 답한다 |

### partially_answerable (Q5)

| 판정 | 조건 |
|------|------|
| **pass** | 답할 수 있는 부분(임플란트 1종·2종 비율)은 정확히 답하고, 답할 수 없는 부분(스케일링)은 문서 근거 없이 거절한다. 문서 외 내용 없음. |
| **partial** | 답할 수 있는 부분이 맞거나 답할 수 없는 부분을 올바르게 거절했으나 둘 중 하나가 불완전하거나, 문서 외 내용이 추가됐다 |
| **fail** | 답할 수 있는 부분에 오답이 있거나, 거절해야 할 부분을 답하거나, 모두 거절한다 |

## 공통 감점 사항

판정을 한 단계 낮추는 조건:

- **문서 외 추론·추정**: "~할 가능성이 높습니다", "일반적으로 ~" 등 검색된 청크에 없는 내용
- **문서 외 연락처**: ☎ 129, ☎ 1577-1000, ☎ 1644-2000 등 PDF에서 검색되지 않은 번호
- **핵심 사실 불명확**: 정답은 맞으나 답변이 모호해서 사용자가 오해할 수 있다

---

## Q2 전용 주의사항

- baseline: Recall@5=0 예상 → `fail` 또는 `partial` 가능
- chunking: A48 Q&A 블록이 단일 청크에 들어가면 → `pass` 기대
- hybrid: BM25가 "틀니", "1종", "5%" 를 키워드로 매칭하면 → `pass` 기대
- 개선 미달이어도 무방. 관찰 사실과 원인을 `human_notes` 에 기록.
